# 小程序发版说明（深圳住区观察）

> 目录：`miniprogram/`，导入微信开发者工具后上传。当前代码对应线上 API 数据版本 `a1cc1b9f`（2026-08-17 观测）。

## 本版变更

- 筛选器面板：新增右上角 × 关闭键，隐藏后左上角显示"筛选"胶囊可重新打开
- 筛选器高度大幅压缩：区域/街道并排一行；导出 CSV / 热力图移入"更多工具"折叠区（默认收起）
- 结果面板右上角改为 × 关闭键
- 修复地图拖拽后回弹到原位置的问题（regionchange 事件不带中心点时按边界计算中心）
- 加载提示改为顶部小胶囊，拖拽刷新不再遮住全屏
- 沿用此前版本功能：官方参考价（挂牌 vs 参考价差值）、租售比榜单切换、学位时间提示、价格趋势历史、范围结果内搜索

## 发版前必须完成的配置（微信公众平台）

1. 合法域名：
   - request 合法域名：`https://map.okzer.xyz`
   - downloadFile 合法域名：`https://map.okzer.xyz`（CSV / 热力图导出用）
2. 隐私保护指引：声明"相册（仅写入）权限"，否则保存热力图到相册会失败。
3. AppID：`miniprogram/project.config.json` 当前为 `touristappid`，替换为正式 AppID 后再上传。

## 提交流程

1. 微信开发者工具导入 `miniprogram/` 目录（或直接用本项目根目录）。
2. 点击右上角"上传"，版本号建议 `1.2.0`，项目备注说明本次变更。
3. 公众平台「版本管理」→ 提交审核 → 审核通过后发布。

## 注意事项

- 小程序所有数据（小区、价格、学校、学区）来自线上 API `https://map.okzer.xyz`，无需随包携带数据文件。
- 本地开发可在开发者工具中关闭"不校验合法域名"（详情 → 本地设置）以便联调，发版必须走正式域名。
