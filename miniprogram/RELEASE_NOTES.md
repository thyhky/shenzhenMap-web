# 小程序发版说明（深圳住区观察）

> 目录：`miniprogram/`，导入微信开发者工具后上传。当前代码对应线上 API 数据版本 `119b810df263`（2026-08-17 观测）。

## 本版变更

- 小程序与手机网页统一为底部三入口：筛选、结果、详情
- 三个面板默认全部关闭；点击底栏后从屏幕底部上拉，关闭后恢复全屏地图
- 点击地图点位、范围结果或榜单小区时自动打开详情抽屉
- 筛选抽屉保留区域/街道、价格、学校/学区开关和更多导出工具
- 结果抽屉整合范围搜索与租售比/价格榜单，详情抽屉保留官方参考价、学位信息和 1周/1月/1季度价格历史
- 沿用地图拖拽不回弹、顶部加载胶囊、CSV 与热力图导出等功能

## 发版前必须完成的配置（微信公众平台）

1. 合法域名：
   - request 合法域名：`https://map.okzer.xyz`
   - downloadFile 合法域名：`https://map.okzer.xyz`（CSV / 热力图导出用）
2. 隐私保护指引：声明"相册（仅写入）权限"，否则保存热力图到相册会失败。
3. AppID：`miniprogram/project.config.json` 当前为 `touristappid`，替换为正式 AppID 后再上传。

## 提交流程

1. 微信开发者工具导入 `miniprogram/` 目录（或直接用本项目根目录）。
2. 点击右上角"上传"，版本号建议 `1.3.0`，项目备注说明本次变更。
3. 公众平台「版本管理」→ 提交审核 → 审核通过后发布。

## 注意事项

- 小程序所有数据（小区、价格、学校、学区）来自线上 API `https://map.okzer.xyz`，无需随包携带数据文件。
- 本地开发可在开发者工具中关闭"不校验合法域名"（详情 → 本地设置）以便联调，发版必须走正式域名。
