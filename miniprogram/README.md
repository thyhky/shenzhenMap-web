# 微信小程序 WebView 容器

这个目录是 `map.okzer.xyz` 的微信小程序容器，不重复实现地图功能。地图、筛选器、学校图层和热力图继续由线上网页提供。

## 开发工具

1. 安装微信开发者工具。
2. 导入本目录 `miniprogram/`。
3. 使用你自己的小程序 AppID 替换 `project.config.json` 中的 `touristappid`。
4. 编译并在模拟器或真机中预览。

## 微信公众平台配置

在小程序后台配置以下域名：

- 业务域名：`https://map.okzer.xyz`
- request 合法域名：`https://map.okzer.xyz`
- downloadFile 合法域名：如果后续增加文件下载，再按实际域名配置

微信会要求完成域名校验。按后台提示将校验文件放到网页工程的 `public/` 目录，再部署 Worker；校验完成后可以移除临时文件。

## 运行边界

- 小程序使用 `web-view` 加载线上页面，因此需要网络连接。
- 小程序的 API 请求仍由网页内部发起，页面使用的 Worker API 不需要在小程序代码中重复实现。
- WebView 版本适合快速上线；后续如果需要更原生的地图体验，再考虑使用微信原生地图组件重写。
- 真机测试时重点检查 WebView 返回、分享、横竖屏和微信业务域名校验。
